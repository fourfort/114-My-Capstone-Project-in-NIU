# 🚀✨ YOLOv8 Algorithm Improvement Project ✨🚀

This repository contains the project files and materials developed during the **1141-1142 academic semesters** as part of a collaborative university research project.  
The project focuses on algorithm design and improvement, with a primary emphasis on the **lightweight module design and architecture planning of the YOLOv8 algorithm**.  

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 📝 Project Overview

🌈 **Objective**: Improve and optimize YOLOv8 by:  
- 🛠️ Designing and implementing lightweight modules  
- 🔄 Replacing and enhancing specific components in the original architecture  
- 📊 Comparing different algorithms through evaluation metrics and training process visualization  

💎 **Contributions**:  
- Main contributor for algorithm design and improvements  
- Development of plots and charts showing training processes and metric comparisons  

🧰 **Tools & Techniques**:  
- YOLOv8 framework  
- Python programming for algorithm implementation  
- Data visualization for evaluation metrics
